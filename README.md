# Sprytile Reborn

<img width="96" height="128" alt="sprytile-logo-export" src="https://github.com/user-attachments/assets/efd9919a-eafb-485f-acce-776744a05a6f" />

Tile-based editor for Blender 5.0+

This project is based on **Sprytile**, originally created by Jeiel Dionisio Aranal and contributors.

It has been heavily modified and updated to support modern versions of Blender.
Not all work perfect, but all main function work and tested with Blender 5.0.1
